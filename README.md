# 🍽️ Restaurant Data Analysis

## 📌 Overview
 
An end-to-end analysis of ~9,500 restaurants to uncover trends in cuisine popularity, pricing, ratings, online delivery adoption, and table booking behavior — combining SQL for data validation and analysis with Power BI for interactive visualization.
 
## 🎯 Objective
 
Identify what drives restaurant performance and customer engagement, and turn that into clear, actionable business recommendations.
 
## 🛠️ Tools Used
 
| Tool | Purpose |
|---|---|
| 🗄️ SQL | Data validation, cleaning, aggregation, analysis |
| 📊 Power BI | Dashboard design, KPI tracking, visualization |
 
## 📂 Dataset
 
- **Records:** ~9,500 restaurants
- **Columns:** 21
- **Fields:** restaurant details, location, cuisines, pricing, ratings, votes, online delivery, table booking
## 🧹 Data Cleaning
 
- ✅ Checked all columns for NULL or blank values using SQL
- ✅ Standardized column names
- ✅ Validated numeric fields (Votes, Ratings, Price Range)
- ✅ Validated categorical fields (Online Delivery, Table Booking)
## 📈 SQL Analysis
 
- Top cuisines identification
- City-wise restaurant count
- Price range distribution
- Online delivery vs. ratings
- Restaurant chain analysis
- Votes analysis
- Price vs. table booking relationship
## 📊 Power BI Dashboard
 
**KPIs tracked:** Total Restaurants · Average Rating · Average Votes · Online Delivery % · Table Booking %
 
**Visuals:** Delivery Availability · Price Range Distribution · Rating Distribution · Top Cuisines · Restaurant Chains · Price vs. Table Booking
 
**Interactivity:** slicers for City, Online Delivery, and Table Booking
 
![Dashboard Screenshot](Screenshot%202026-01-29%20113540.png)
 
## 🔍 Key Insights
 
- 💰 Most restaurants fall in the budget price tier (Price Range 1)
- 🚚 Only ~26% of restaurants offer online delivery — but those restaurants rate higher
- 🍛 North Indian cuisine dominates the market
- ☕ Cafe Coffee Day is the most common restaurant chain
- 🪑 Higher-priced restaurants offer more table booking services
## 💡 Business Recommendations
 
- Expand online delivery services to capture the ratings advantage it brings
- Improve the dine-in experience at premium restaurants
- Diversify cuisine offerings beyond the North Indian majority
- Use customer feedback to improve consistency across restaurant chains
- Target high-density cities for marketing spend
## ✅ Conclusion
 
This project provided hands-on experience in SQL-based data validation, Power BI dashboard design, and translating raw data into business insight.
