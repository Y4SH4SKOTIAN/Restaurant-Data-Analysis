# Restaurant-Data-Analysis
Restaurant Data Analysis 
📌 Project Overview

The objective was to analyze restaurant data and identify trends related to cuisines, pricing, ratings, online delivery, table booking, and restaurant chains using SQL and Power BI.

🛠 Tools Used

SQL (Data validation & analysis)

Power BI (Dashboard & visualization)

📊 Dataset Information

Records: ~9,500 restaurants

Columns: 21

Includes restaurant details, location, cuisines, pricing, ratings, votes, online delivery, and table booking information.

🔧 Data Cleaning

Verified all columns for NULL or blank values using SQL

Standardized column names

Checked numeric fields (Votes, Ratings, Price Range)

Validated categorical fields (Online Delivery, Table Booking)

Dataset was clean and ready for analysis.

📈 Analysis Performed (SQL)

Top cuisines identification

City-wise restaurant count

Price range distribution

Online delivery vs ratings

Restaurant chains analysis

Votes analysis

Price vs table booking relationship

📊 Power BI Dashboard
KPIs:

Total Restaurants

Average Rating

Average Votes

Online Delivery %

Table Booking %

Visuals:

Delivery Availability

Price Range Distribution

Rating Distribution

Top Cuisines

Restaurant Chains

Price vs Table Booking

Interactive slicers added for City, Online Delivery, and Table Booking.

🔍 Key Insights

Most restaurants fall under Price Range 1 (budget market).

Only ~26% restaurants offer online delivery, but they have higher ratings.

North Indian cuisine dominates.

Cafe Coffee Day is the most common chain.

Higher price restaurants provide more table booking services.

📌 Business Recommendations

Expand online delivery services

Improve dine-in experience for premium restaurants

Diversify cuisine offerings

Use customer feedback to improve chain consistency

Target high-density cities for marketing
